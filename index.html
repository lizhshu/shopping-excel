使用说明

  1. 内置数据：打开即载入清单，无需上传；如需查看其他表格，点「上传表格替换」读取 .xlsx / .xls / .csv / .tsv（读取第一个工作表，首行为表头），之后可「恢复内置数据」。
  2. 查看提取结果：仅显示指定的 11 列，表头为中文；点击「品牌（中文）」单元格即可复制该名称。
  3. 筛选与排序：种类、产品名称均为多选（选项来自原表实际内容）；「搜索」框可按任意列关键词全文匹配；「隐藏列」可多选隐藏不需要的列；排序只作用于筛选后的结果，折扣力度按 0.1 → 0.2 由大到小。
  4. 缩放与自适应：− / + 调整表格字号，窗口变化时布局自动适配，表格可横向滚动。
  5. 考虑清单：行尾「加入」把商品放到页面底部清单，「一键复制」导出清单全部内容。
列匹配规则

表头只做三项归一化：大小写、中英文括号、空格（含全角空格），归一化后必须完全一致才视为同一列。不做近似猜测，避免把不同列混在一起或把错误表头认进来；未匹配到的列留空并在页面上方提示。
